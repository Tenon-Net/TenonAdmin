# 等保三级 · 第一期页面验收清单

- **范围**：仅第一期（认证 / 会话 / MFA / 策略下限 / 预检接口）
- **模板**：Vue `web/` 与 React `web-react/` 行为对齐；下文以 **Vue 菜单路径** 为主，React 同功能页面等价验收
- **前提**：后端已启用 `TenonAdmin:Security:Profile=Level3`，并按 `docs/agents/mlps-level3-cookie-csrf-deploy.md` 配好 Cookie/CSRF 拓扑（本地同源推荐）
- **声明**：本清单验收的是「一期能力可在页面上走通」，**不是**等保测评结论，不得据此宣称已通过等保三级
- **填法**：每项完成后在「结果」填 `通过` / `不通过` / `阻塞`；「意见」写现象、截图说明或缺陷描述

### 建议验收账号

| 角色 | 用途 |
|------|------|
| 超管 A（已绑 TOTP） | 发邀请、高敏配置、再认证、安全策略 |
| 普通用户 B（未绑 TOTP） | 收邀请、完成绑定、恢复码、强制 TOTP 登录 |
| 可选：第二浏览器/无痕 | 并发会话、Cookie 隔离 |

### 推荐工具

- 浏览器开发者工具 → **Application / Storage**（Cookie、Local Storage）
- **Network**（登录响应体、写操作请求头 `X-Tenon-CSRF`）
- Authenticator 应用（Google Authenticator / Microsoft Authenticator 等）
