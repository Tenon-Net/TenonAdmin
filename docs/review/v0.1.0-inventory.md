# TenonAdmin v0.1.0 发版前功能清单（review 核对表）

这份清单是发版前逐项 code review 的**分母**：先把"这个系统到底有哪些功能"列全，再一项一项过代码。review 结论记在 [`v0.1.0-findings.md`](v0.1.0-findings.md)。

规模：**17 个控制器 / 76 个接口**（外加 `/health`、`/health/ready`、`/openapi/v1.json`）、**31 个服务**、**20 张表**、**16 项横切机制**；前端 **33 个页面 + 24 个共享组件**。后端 211 个测试，前端 0 个单测（3 个 Playwright 用例，且不在 CI）。

---

## 一、特色功能（这套内核区别于普通后台模板的地方）

| # | 特色 | 核心实现 |
|---|---|---|
| T1 | **多机构数据权限**（五种数据范围，查询层自动生效） | `DataScopeProvider` + `SqlSugarSetup` 的 `IOrgScoped` 全局过滤器 + `SqlSugarRepository` 的写路径守卫 |
| T2 | **权限码即路由**（代码里没有权限字符串） | `PermissionCode.Build` + `RolePermissionAttribute` + `MenuController.Routes` 现场枚举可授权端点 |
| T3 | **可替换性四层**（配置 → 换服务 → 继承重写 → 覆盖端点） | 全量 `TryAdd` 注册 + `virtual` 模板方法 + `ApplicationAssemblies` + `DisabledModuleConvention`；由"六件套" `ReplaceabilityTests` 锁死 |
| T4 | **多应用门户**（一套后台装多个应用，各自菜单树） | `ModuleService` + `portal:gen` 代际计数器做 O(1) 全局失效 |
| T5 | **配置中心**（改配置不改代码：安全/上传/限流/基础） | `SysConfig` + `SecurityPolicyProvider`（DB 优先、Options 回落）+ `RuntimeRateLimit` 快照 |
| T6 | **分片上传：续传 + 秒传** | `ChunkStorage` + `FileService.ChunkInit/SaveChunk/ChunkComplete`（按内容哈希秒传，按已收分片续传） |
| T7 | **多副本正确性** | Redis 缓存共享 + 限流计数跨副本 + 每副本独立雪花 WorkerId（不给就启动即报错）+ GC 每 tick 只跑一个副本 + 反代后取真实客户端 IP |
| T8 | **零配置启动** | 默认 SQLite + CodeFirst 建表 + 幂等种子 + 首启打印随机超管密码；生产环境自动关闭建表并改为"缺列即报错" |
| T9 | **回收站**（软删的行可恢复/可硬删） | `RecycleBinController` + `SqlSugarRepository.RestoreAsync`（含唯一列冲突检测） |

### 横切机制（16 项）
数据权限过滤器、软删过滤器、审计字段 AOP 自动填充、雪花 ID（含多副本 WorkerId 守卫）、权限码即路由、JWT + 轮换 + 生产缺密钥 fail-fast、会话与强制下线、限流（跨副本共享计数）、统一响应信封、异常过滤器与数字错误码、缓存（Memory / Redis 双实现 + 键目录）、进程内事件总线、上传与 GC、启动建表与种子（生产闸门 + 缺列守卫）、配置中心、反代真实 IP、可替换性（TryAdd + virtual + 六件套测试）。

### 前端（33 页 + 24 组件）
- **页面**：登录（3 套皮肤）、工作台、用户、角色（授权菜单/数据范围/授权用户三个抽屉）、菜单（含按钮管理）、机构、职位、模块、字典（主从）、配置（4 个 tab）、操作日志、登录日志、公告、文件、在线会话、回收站、个人中心（资料/改密/我的公告）、应用选择、404。
- **组件**：FormContainer、StatusSwitch、ApiSelect、UserSelect、RoleSelect、UserPicker、OrgTreeSelect、DictSelect/DictTag/DictRadio/DictCheckbox、FileUpload、PasswordStrength、JsonEditor、MarkdownEditor/View、Chart（Line/Pie/Bar）、IconPicker、AppIcon、MenuSearch、TenonLogo。
- **机制**：契约生成的 API 客户端（`schema.d.ts`）、401 单飞续期、动态路由注入（多应用）、`v-auth` 按钮级权限、i18n（错误码按 MsgKey 翻译）、主题 token + 暗色、6 种布局模式、多标签页。
