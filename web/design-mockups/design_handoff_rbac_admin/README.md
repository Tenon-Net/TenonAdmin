# 交接文档：企业级 RBAC 权限管理后台

## 概述
一套企业级权限管理（RBAC）后台的高保真设计原型，包含登录页（3 种版式）、数据总览、工作台、角色管理（列表+权限详情）、用户管理（表格+新建抽屉）、系统设置（资料/安全/通知）、空状态与 404。支持亮/暗双主题、侧栏收起、可调主色与信息密度。

## 关于设计文件（重要）
本包内的 HTML 文件是**用 HTML 制作的设计参考稿** —— 它们展示预期的外观与交互，**不是可直接上线的生产代码**。你的任务是**在目标代码库的既有技术栈中还原这些设计**（React / Vue / Angular / SwiftUI 等），沿用该项目已有的组件库、路由、状态管理与样式方案。若项目尚无技术栈，请为其选择最合适的框架再实现。

- `企业后台原型.dc.html` 依赖同目录的 `support.js` 运行时才能在浏览器打开预览。它由一个模板 + 一个逻辑类驱动，**仅供参考视觉与交互**，不要照搬这套运行时。
- `设计系统-Design-Tokens.html` 是自包含的设计规范说明页，可直接双击打开查看所有令牌（颜色/字体/间距/圆角/阴影）及组件示例。

## 保真度
**高保真（Hi-fi）**：颜色、字体、间距、圆角、交互均为最终值，请按下述令牌像素级还原，并接入你代码库的既有组件。

标签/徽章底色由 base 程序化推导：亮色 = base 混 88% 白，暗色 = base 混 80% bg-container；文字 = base 亮色混 6% 黑 / 暗色混 18% 白。

### 派生规则（供动态主色 / 主题使用）
- `mix(a,b,t)`：按 t 在两色间线性插值。
- primary(暗) = mix(accent, #FFF, 0.18)；hover = mix(primary, #FFF, 0.16)；pressed = mix(primary, #000, 0.18)。
- primary-light：亮 = mix(primary, #FFF, 0.90)，暗 = mix(primary, bg-container, 0.82)。
- 主按钮渐变 `btnGrad` = `linear-gradient(135deg, accent 0%, mix(accent,#8B5CF6,0.55) 55%, mix(accent,#EC4899,0.62) 100%)`。
- 按钮发光 `glowSh` = `0 6px 20px rgba(accent,0.42)`；hover 上浮 `translateY(-2px)`。

### 字体
- 主字体：`'Noto Sans SC', -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`
- 等宽（编号/代码/时间戳）：`'JetBrains Mono', monospace`
- 字号阶梯：12 / 13(正文次要) / **14(正文默认，行高 22)** / 16 / 20 / 22–23(页面标题) / 大标题 42–52(登录页)
- 字重：正文 400，强调 500，标题 600–700，登录大标题 700–800

### 间距 / 圆角 / 阴影
- 间距基准 4px 网格：4 / 8 / 12 / 16 / 24 / 32。页面内边距 24（紧凑 18）；卡片间距 16（紧凑 12）。
- 卡片内边距：舒适 `20px 22px` / 紧凑 `16px 18px`；表格行高：舒适 58 / 紧凑 48。
- 圆角：控件/标签 4–8，输入/按钮 10–12，卡片 12–14，登录卡 16–18。
- 阴影：
  - shadow1（卡片）亮 `0 1px 2px rgba(20,27,45,.04), 0 2px 6px rgba(20,27,45,.06)`
  - shadow2（悬浮/弹层）亮 `0 10px 30px rgba(20,27,45,.12)`
  - 暗色对应用更深的黑色阴影。

## 全局框架（应用外壳）
- CSS Grid：`grid-template-columns: [侧栏宽] 1fr`。侧栏宽展开 236px / 收起 76px（收起时隐藏所有文字标签，仅留图标）。
- 侧栏 sticky 满高，内部分：Logo 区(高 60–62) → 分组菜单(可滚动) → 底部次要链接。
- 顶栏 sticky，高 62，`backdrop-filter: blur(12px)`，含：折叠按钮、面包屑、搜索框(⌘K)、亮/暗主题切换 pill、通知铃(红点)、用户头像+姓名。
- 图标为 24×24 viewBox 的线性 SVG（stroke 1.7），跟随主题上色。

### 4. 角色管理 Roles（列表 + 权限详情）
- 顶部标题 + 「新建角色」主按钮。

### 5. 用户管理 Users（表格 + 新建抽屉）
- 工具条：搜索、角色筛选 chip、筛选按钮、「新建用户」主按钮。
- 表格列：用户(头像+姓名+邮箱) / 角色(彩色标签) / 部门 / 状态(圆点徽章) / 最近登录 / 操作(编辑)。行 hover 换底。8 行示例 + 分页器。
- **抽屉表单**：点“新建用户”或“编辑”从右侧滑入（440px，`slideIn` cubic-bezier(.16,1,.3,1) 0.3s）；遮罩点击关闭。字段：姓名*/账号*/邮箱*/手机/部门 + 分配角色(chip 多选) + 状态开关；底部“取消/创建用户”。

### 6. 系统设置 Settings（左侧标签 + 右侧内容）
- 左侧标签：基本资料 / 安全设置 / 通知设置（选中 primary-light 底 + 主色字）。
- **基本资料**：头像(btnGrad)+更换按钮、两列表单(姓名/昵称/邮箱/手机/部门)、个人简介 textarea、保存/重置。
- **安全设置**：登录密码/绑定手机/两步验证(开关)/登录设备 列表项。
- **通知设置**：4 个开关项(权限申请/安全告警/系统维护/每周摘要)。
- 开关：46×26 轨道，圆点 20，开=主色底、圆点右移 23px；`transition .2s`。

### 7. 空状态 & 404
- 空状态(回收站)：45° 条纹虚线占位框 + 主色图标柔光 + 文案 + 返回按钮。
- 404：超大数字(可选主色渐变字)、飘浮方框装饰、返回工作台 / 返回登录。

## 交互与动效
- **路由**：单页状态切换（无真实 URL），侧栏点击切换页面并 `window.scrollTo(0,0)`；页面进入 `fadeUp .34s`。
- **主题切换**：顶栏/登录页 pill，切换 light/dark，全局颜色令牌整体替换。
- **侧栏收起**：折叠按钮切换宽度 236↔76，隐藏文字。
- **抽屉**：`slideIn`；遮罩 fadeIn 0.2s。
- **卡片/磁贴 hover**：`translateY(-3px)` + shadow2。
- **登录按钮高光**：`shine` 扫光（仅“炫酷”特效档）。
- **环境动效**（仅“炫酷”档；“沉稳”档全部设为 `none`）：柔光块 `blob` 漂浮、渐变位移 `gradShift`、装饰方框 `floaty`。
- 关键 `@keyframes`：`fadeUp / fadeIn / slideIn / floaty / blob / gridPan / gradShift / glowPulse / shine / riseFade`。

## 状态管理（原型内部）
- `route`：当前页面（login/dashboard/workbench/roles/users/settings/empty/404）
- `theme`：light | dark
- `loginVariant`：0/1/2（登录版式）
- `dashVariant`：0/1（总览布局）
- `collapsed`：侧栏是否收起
- `selectedRole`：角色列表选中项索引
- `drawerOpen`：用户抽屉开关
- `settingsTab`：basic | security | notify

## 可配置项（原型的 Tweaks / 建议做成主题配置）
- **主色 accent**：6 个候选色（默认 `#646CFF`）—— 全站主色、渐变、发光、选中态由它推导。
- **特效强度 fx**：炫酷 / 沉稳（沉稳关闭全部环境动画，适合正式场景）。
- **信息密度 density**：舒适 / 紧凑（影响页面内边距、卡片间距、表格行高、卡片内边距）。
- **品牌名称 brandName**：文本。
