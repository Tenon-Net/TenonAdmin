# 登录背景素材

两张 WebP 来自用户在本次登录页改造中提供并授权借鉴的静态预览图，不含登录 UI、品牌标志或可交互文字。

- `brand-light.webp`：`01_light_brand.png` 的建筑场景，裁剪原图 `(0, 675)–(725, 1005)`；裁剪前对剩余示意文字区域作表面颜色插值修补。
- `brand-dark.webp`：`02_dark_material.png` 的无文字石墨曲面，裁剪原图 `(0, 108)–(798, 682)`。

原始参考图由用户保存在 `.orca/drops/`。运行时只依赖本目录内的素材。图片由 Pillow 裁剪和压缩，未调用图片生成 API；两张共约 37 KB。文本与 Logo 始终由页面组件单独渲染。

## 产品展示

`product-preview.webp` 来源于仓库已有 `docs/screenshots/vue-admin.png`，裁剪掉底部空白后缩为1280×624并转为WebP。它是本项目Vue模板的静态用户管理界面，保留原始中文，不在登录前请求或展示当前部署的用户数据；图片说明随页面语言切换。

## 独立浅色品牌皮肤

`light-brand-scene.webp` 仅供新增 `light-brand` 皮肤使用。来自本轮 ZIP 内 `01_light_brand.png` 的 `(0,550)–(725,1086)` 装饰区，保留玻璃体完整轮廓、球体和台阶；清除原稿的功能说明、玻璃体示意文字及底部文案后压缩为 WebP（725×536，约 12KB）。清理采用同一表面像素插值，未生成新的三维素材。实际页面中的文字、正式 Logo、工具栏及表单单独渲染。深色仍使用这一场景，仅降低亮度；不引用其他候选图。React 模板保存独立副本。
