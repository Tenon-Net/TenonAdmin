# 第三方登录品牌图标（请自行放入）

对齐 Gitee 登录页那种：**整颗彩色圆标**（圆底 + 品牌白/彩字），不是灰底单色线标。

## 放什么文件

| 文件名（固定） | 对应登录方式 |
|----------------|--------------|
| `wechat.svg` 或 `wechat.png` | 个人微信 |
| `wecom.svg` 或 `wecom.png` | 企业微信 |
| `dingtalk.svg` 或 `dingtalk.png` | 钉钉 |
| `github.svg` 或 `github.png` | GitHub |
| `gitee.svg` 或 `gitee.png` | Gitee |
| `qq.svg` 或 `qq.png` | QQ |

同名 `.svg` 优先于 `.png`。放好后**重启 dev / 刷新**即可，无需改代码。

## 下载规格（照这个下）

| 项 | 建议 |
|----|------|
| **格式** | **首选 SVG**；没有再下 **PNG** |
| **画布** | **正方形**，内容居中 |
| **PNG 像素** | **至少 128×128**，推荐 **256×256**（登录钮约 44px，@2x/@3x 不糊） |
| **视觉样式** | **彩色圆形完整标**（圆底已画进图里）——和 Gitee 那排一样 |
| **画布比例** | **必须 1:1 正方形**（如 256×256）。非正方形（例如企微宽图）套圆后会扁/空 |
| **圆要铺满** | 彩色圆尽量贴满 viewBox/画布边缘；四周留白大会「看起来小一圈」（如原先 QQ） |
| **透明** | 圆外透明；不要白方底 |
| **不要** | 线框黑白标、长方形 logo、带大段文字的 banner |

## 和 Gitee 的结构对齐

Gitee 登录页第三方是 **`<a href="授权地址">`**，不是 `<button>`。本仓库登录区已改成同样的 `<a class="lf-sso-btn" href=".../authorize">`。

## 去哪下

1. [iconfont.cn](https://www.iconfont.cn/) 搜「微信」「钉钉」「企业微信」「github」「qq」  
   - 筛选：**彩色 / 面性 / 圆形**  
   - 下载时选 **SVG** 或 **PNG@2x / @3x**  
2. 或各厂商 **品牌资源 / Brand Kit** 里的 App Icon / 圆形标
